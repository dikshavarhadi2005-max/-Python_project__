# 🧮 Simple Calculator in Python

A beginner-friendly Python project that performs basic arithmetic operations using functions and conditional statements. This project is ideal for students learning Python fundamentals such as functions, user input, and decision-making.

---

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Average of two numbers
- User-friendly menu-driven interface

---

## 🛠️ Technologies Used

- Python 3

---

## 📂 Project Structure

```
Simple-Calculator/
│
├── calculator.py
└── README.md
```

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/simple-calculator.git
```

2. Navigate to the project folder

```bash
cd simple-calculator
```

3. Run the program

```bash
python calculator.py
```
